## metrics for projects

### Downloader metadata

For an enrolled namespace, Maven Central Basic Publisher Insights provides the following metadata about downloads and their sources:

- Total artifact downloads
- Unique sources, derived from IP address, user agent, and other request attributes
- Number of inferred companies
- Connection categories such as business, ISP, hosting/cloud, government, and education
- Three months of Basic Insights history

This does not include publishing activity, release administration, or organization-member metadata.

Source: [Sonatype Publisher Insights — Basic Insights](https://central.sonatype.org/publish/publish-portal-insights/#basic-insights)

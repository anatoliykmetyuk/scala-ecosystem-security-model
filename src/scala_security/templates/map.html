ABOUT THIS WORLD

A map of shared responsibility.

Click a country to inspect its details. Use the project’s compromise button, or enable Compromise mode to toggle compromises directly on the map. Click open map space to clear the selection. Search selects a project and returns to inspection mode.

This is a storytelling companion to the Scala ecosystem security report. Countries represent repositories. Larger countries generally represent more-starred projects; their areas are illustrative and stay fixed when scores are refreshed.

Security and Maintenance describe observed practices and activity, not proven safety. Unknown scores remain unknown. Exposed Value adds the provisional, star-based Value of distinct verified dependants.

Compromising a component highlights its verified dependant set, up to five dependency hops. It does not predict exploitability or infection probability. Geography, mountains, rivers, and proximity carry no dependency meaning.

Affected totals combine directly compromised projects and exposed dependants, counting each project once. The Value percentage uses the sum of known project Values as its denominator; unknown Values are reported separately. Hover connections are off by default. When enabled, they show all verified downstream relationships retained in this snapshot.


Only the snapshot's selected seed projects and artifacts are represented. Missing evidence and collection limits can hide relationships. Dates refer to the snapshot; cached observations can be older.
